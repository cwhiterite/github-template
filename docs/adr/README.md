# Architecture Decision Records

One file per structural decision: `NNNN-short-title.md`, copied from
[`0000-template.md`](0000-template.md).

Write one when you add a dependency, choose a database or framework, change the
data model, or introduce a new pattern. Skip it for routine changes.

**On a feature branch**, name the draft `XXXX-short-title.md` and list it in your
`docs/changes/` fragment. `consolidate-docs` assigns the real number and adds it to
this index, so two branches can't take the same number.
